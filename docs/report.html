1. Введение

Этот документ описывает результаты реверс-инжиниринга аркадной игры Moon Patrol (Irem, 1982). Цель — получить полное понимание игровой архитектуры для последующей реимплементации на C++ с SDL3 (проект Moon Patrol ND).

Методология: статический анализ ROM-файлов через radare2 (Z80-дизассемблер), поиск байтовых сигнатур, ручная расшифровка инструкций, сравнение трёх версий игры (Irem, Williams, bootleg).

IRQ делает:

  1. CALL $056D (видео).
  2. Инкремент кадрового счётчика 0xE04E.
  3. Раз в 16 кадров — инкремент 0xE04F.
  4. Декремент таймеров 0xE050/0xE051.
  5. Проверка DIP 0xD004.
  6. Задержка ~768 тактов (синхронизация с CRT).

Логика:

  1. Вызвать 6 подсистем.
  2. Итерировать объекты 0xE600+.
  3. Для каждого с state 1-0x7F — dispatch через таблицу 0x02D3.
  4. Если все обработаны → новый кадр.

9.1 0x0DDC — скриптовый движок

Читает скрипт из 0x2162+. 24 типа команд. Вызывает 0x125B (RLE), 0x1106 (parallax), 0x29D6.

9.2 0x210D — HUD/score

BCD-арифметика (DAA). Счётчик 0xE511–0xE512, растёт каждые ~3 сек (183 кадра). Отображается в 0x8090.

9.3 0x1B3A — спавн врагов

Использует R-регистр Z80 как PRNG: LD A, R; AND $F0. Раз в ~3 секунды (таймер 0xE0EE).

9.4 0x1BC7 — стрельба

Раз в 32 кадра (AND $1F). Ищет свободный слот из 3 (0xE1C6–0xE1C8). Спавнит пулю.

9.5 0x12A7 — коллизии

Проверяет слоты 0xE370+ на типы 0x14, 0x1E-0x1F, 0x20-0x21, 0x22-0x29. При совпадении — звук.

9.6 0x12E7 — анимация

Каждые 2 кадра — следующий кадр из 0xE1DA+. Терминатор 0x5A.

11. Логика игрока (лунохода)

11.1 Точка входа: 0x0831

Player update вызывается из 6 контекстов в mpa-2.3l: 0x162D, 0x18E0, 0x1957, 0x195E, 0x1A2F, 0x1E25.

0x0831  3A 00 E3    LD A, ($E300)       ; game state
0x0834  FE 06       CP $06
0x0836  30 7A       JR NC, $08B2        ; state >= 6 → выход
0x0838  3A E2 E1    LD A, ($E1E2)       ; scroll
0x083B  DD 96 0F    SUB (IX+$0F)        ; scroll - world_X
0x083E  ED 44       NEG                 ; world_X - scroll = screen_X
0x0840  DD 77 03    LD (IX+$03), A      ; [ix+0x03] = screen_X
0x0843  FE E0       CP $E0
0x0845  38 6D       JR C, $08B4         ; dispatcher

11.2 Диспетчер: 0x08B4

0x08B4  DD 36 0B 01  LD (IX+$0B), $01    ; active = 1
0x08B8  DD 7E 0D     LD A, (IX+$0D)      ; move_type
0x08BB  07           RLCA                ; бит 7 → C
0x08BC  D8           RET C               ; если бит 7 → выход
0x08BD  17           RLA
0x08BE  21 18 2E     LD HL, $2E18        ; таблица параметров
0x08C1  30 01        JR NC, +1
0x08C3  24           INC H               ; HL = $2F18
0x08C4  5F           LD E, A
0x08C5  16 00        LD D, $00
0x08C7  19           ADD HL, DE
0x08C8  DD 5E 01     LD E, (IX+$01)      ; type
0x08CB  16 E1        LD D, $E1
0x08CD  FD 21 00 00  LD IY, $0000
0x08D1  FD 19        ADD IY, DE           ; IY = 0xE100 + type
0x08D3  56           LD D, (HL)           ; байт 0
0x08D4  23           INC HL
0x08D5  5E           LD E, (HL)           ; байт 1
0x08D6  23           INC HL
0x08D7  4E           LD C, (HL)           ; action_index
0x08D8  06 00        LD B, $00
0x08DA  21 F5 08     LD HL, $08F5         ; jump table
0x08DD  09           ADD HL, BC
0x08DE  4E           LD C, (HL)
0x08DF  23           INC HL
0x08E0  66           LD H, (HL)

0x08ED  2F          CPL                 ; ~A

26. Приложение: карта подсистем

26.1 Game loop 0x026E

1. CALL 0x0DDC (скрипт)
2. CALL 0x210D (HUD)
3. CALL 0x1B3A (спавн)
4. CALL 0x1BC7 (пули)
5. CALL 0x12A7 (коллизии)
6. CALL 0x12E7 (анимация)
7. CALL 0x0DDC (ещё раз)
8. Итерация объектов 0xE600+ через 0x02D3
9. Если все → goto 1

26.2 Player state machine

0x0831:
  screen_X = world_X - scroll
  if screen_X >= 0xE0: despawn
  else: → 0x08B4

0x08B4:
  active = 1
  if move_type & 0x80: return
  table = (move_type & 1) ? 0x2F18 : 0x2E18
  action = table[(move_type>>1)*3 + 2]
  B = button_state + ~prev_btn
  jp 0x08F5[action]
    handler: write sprite, chain or ret

27.3 Полные листинги

for f in mpa-1.3m mpa-2.3l mpa-3.3k mpa-4.3j; do
    case $f in
        mpa-1.3m) off=0    ;;
        mpa-2.3l) off=1000 ;;
        mpa-3.3k) off=2000 ;;
        mpa-4.3j) off=3000 ;;
    esac
    r2 -qc "pd 4096" -a z80 -b 16 -m $off $f > "$f.asm"
done
