⚡ Быстрый старт

1. Зависимости (macOS)

brew install sdl3 sdl3_image cmake

2. Ассеты из ROM

Нужны легально приобретённые ROM-файлы. Положить в orig_rom/ рядом с mpng_src/:

python3 tools/decode_bg.py
python3 tools/extract_level.py
python3 tools/extract_known.py

3. Сборка

cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j

4. Запуск

./build/moon_patrol_nd.app/Contents/MacOS/moon_patrol_nd

🌍 Игровая модель

Зоны (26, A–Z) и 8 групп

ГруппаЗоныНазначение
1Aтренировочная
2B C D E—
3F G H I—
4J K L M—
5N O P Q—
6R S T U—
7V W X Y—
8Zфинальная
  • 1 зона = 2000 px при auto_speed = 80 px/сек → 25 секунд
  • Полная игра ≈ 11 минут (26 зон)
  • 3 жизни — при смерти respawn на чек-поинте
  • Чек-поинт = первая буква текущей группы (погиб в E → старт с B; погиб в O → старт с N)
  • Все 3 жизни потеряны → GAME_OVER

HUD (на русском)

ЗОНА:A   ВРЕМЯ:00   ОЧКИ:00000   ЖИЗНИ:3   РЕЖИМ:EASY
  • ЗОНА — текущая буква A–Z
  • ВРЕМЯ — секунды в текущей зоне (сбрасывается при переходе)
  • ОЧКИ — за сбитые NLO / бомбы / камни
  • ЖИЗНИ — остаток жизней
  • РЕЖИМ — EASY / NORMAL / HARD

Счёт

СобытиеОчки
Горизонтальная пуля × NLO+100
Вертикальная пуля × NLO+100
Стрельба по камню+50
Сбитая бомба+50

✅ Что готово

Игровой мир

  • 3 слоя параллакса + 12 случайных палитр
  • Звёздное небо (120 точек, 3 слоя параллакса — slow/normal/fast)
  • Луноход: движение, прыжок, стрельба (горизонтальная + вертикальная)
  • NLO (тарелки), BOMBA (бомбы), препятствия (яма / камень / кратер)
  • Счёт, пауза, game over, restart
  • Экраны: ATTRACT / GAME_OVER / SCORE

Геймплей (v20261030)

  • 26 зон A–Z + 8 групп
  • 3 жизни + чек-поинты (по первой букве группы)
  • Русский HUD (шрифт 5×7 + UTF-8, 13 кириллических глифов)
  • Смешанный счёт: дистанция-зоны + очки за убийства

Технически

  • VSync 60 Гц, защита от зависаний (dt-кап)
  • Полный реверс-инжиниринг ROM (docs/report.html)

⚖️ Правовая заметка

ROM-файлы Moon Patrol © Irem / Williams. Они не входят в репозиторий и должны быть приобретены/найдены пользователем отдельно.

assets/* — производные (декодированные) из ROM — не коммитятся в git (см. .gitignore), генерируются локально.

Код игры — независимая реимплементация, не содержит оригинальных ROM.
